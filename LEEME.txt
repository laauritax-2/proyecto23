PROYECTO 23 - APLICACIÓN WEB DEL TIEMPO

ARCHIVOS
- index.html: estructura de la página.
- style.css: diseño y adaptación a celulares.
- script.js: búsqueda de ciudades y consulta de datos meteorológicos.

CÓMO EJECUTAR
1. Descomprime la carpeta.
2. Abre la carpeta PROYECTO-23 en Visual Studio Code.
3. Abre index.html con Live Server.
4. Permite el acceso a la ubicación cuando el navegador lo solicite.
5. Si no deseas compartir tu ubicación, escribe una ciudad en el campo de búsqueda.

API UTILIZADA
Open-Meteo (gratuita y sin clave API):
https://open-meteo.com/

NOTA
La aplicación necesita conexión a internet para consultar la API.
La ubicación automática funciona en localhost (Live Server) o en una página publicada con HTTPS.
